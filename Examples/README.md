# Examples

## XDDesignKitDemo

`XDDesignKitDemo` is a UIKit demo app for previewing components without integrating the package into any business project.

Open:

```text
Examples/XDDesignKitDemo/XDDesignKitDemo.xcodeproj
```

Run the `XDDesignKitDemo` scheme on an iOS Simulator.

Current preview sections:

- Colors
- Typography
- Buttons

The Buttons section links to a standalone interactive XDButton screen with style, state, placement, RTL, theme, light/dark, loading, long-text, and native-image controls.
